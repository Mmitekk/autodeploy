1
Копируем файлы сайта на сервер
Переносим готовый сайт на хостинг

Скопируйте все файлы сайта на сервер в папку, название которой совпадает с вашим доменом. Например, для сайта narkozav7.ru это будет папка /var/www/narkozav7.ru.

Важно: все файлы должны лежать прямо внутри этой папки, а не в дополнительной подпапке.

Команда для копирования
# Копируем файлы на сервер
scp -r ./site-files/* root@your-server:/var/www/narkozav7.ru/
✓

Если вы не знаете, как подключиться к серверу — используйте программу для SSH-доступа (например, PuTTY на Windows или Terminal на Mac) с данными, которые предоставил хостинг.

2
Создаём репозиторий на GitHub
Нужен, чтобы нейросеть могла обновлять сайт ВИДЕО

Репозиторий — это хранилище кода сайта на GitHub. Благодаря ему нейросеть сможет вносить изменения в сайт и автоматически обновлять его на сервере. Посмотрите видеоинструкцию, а затем выполните шаги ниже.

  1. Зайдите на github.com и нажмите кнопку New repository (новый репозиторий)
  2. В качестве имени укажите ваш домен, например be6st.ru
  3. Поставьте галочку Private (приватный), чтобы код сайта не был виден посторонним
  4. Создайте токен доступа — это специальный пароль для скрипта. Для этого: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
⚠

Сохраните токен сразу! После создания GitHub покажет его только один раз. Без токена скрипт не сможет подключиться к репозиторию. При создании токена убедитесь, что дали ему права на Contents, Webhooks и Administration.

ⓘ

Как понять, кто владелец репозитория: посмотрите на ссылку — например, https://github.com/Mmitekk/be2st.ru. Здесь Mmitekk — это владелец (логин), а be2st.ru — название репозитория. Эти данные понадобятся при запуске скрипта.

3
Запускаем скрипт развертывания
Скрипт сам сделает почти всё за вас

Подключитесь к серверу, перейдите в каталог скрипта и запустите его. Он задаст несколько вопросов, а всё остальное сделает автоматически: установит нужные программы, соберёт сайт, запустит его и настроит обновления.

cd /var/www
python3 autodeploy.py
  1. Название проекта — введите домен вашего сайта, например be6st.ru
  2. Путь к сайту — полный путь на сервере, например /var/www/be6st.ru
  3. Режим запуска — введите 1 (Standalone — это рекомендуемый режим)
  4. Домен и SSL — введите ваш домен. Если домен уже привязан к серверу и нужен безопасный протокол (HTTPS) — нажмите y. Если домен ещё не опубликован — нажмите n
  5. Логин владельца GitHub — логин из ссылки на репозиторий (например, Mmitekk)
  6. Название репозитория — имя репозитория из ссылки (например, be2st.ru)
  7. Приватный? — нажмите y
  8. Токен GitHub — вставьте токен, который вы создали на шаге 2
  9. Ждите — скрипт автоматически установит все зависимости, соберёт сайт, запустит его и настроит автоматические обновления. Это может занять несколько минут
✓

После завершения скрипта ваш сайт будет доступен по адресу домена. А при каждом обновлении кода в GitHub сайт будет автоматически обновляться на сервере.
