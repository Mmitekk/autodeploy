# AutoDeploy — Автоматический деплой нейросайтов на VDS

Скрипт для автоматического развертывания сайтов, созданных с помощью нейросети, на сервере VDS. Выполняет полную настройку: от установки зависимостей до запуска и настройки автоматических обновлений через GitHub Webhook.

## Что делает скрипт

Из 15 блоков деплоя только **4 требуют ручного ввода** — остальные выполняются автоматически:

| # | Блок | Тип | Описание |
|---|------|-----|----------|
| 1 | Название проекта и путь | MANUAL | Ввод данных |
| 2 | Выбор свободного порта | AUTO | Автоматически |
| 3 | Режим запуска | MANUAL | Standalone / Standard / Auto |
| 4 | Домен и SSL | MANUAL | Let's Encrypt опционально |
| 5 | Подготовка PM2 | AUTO | ecosystem.config.js |
| 6 | Веб-сервер | AUTO | Nginx / Apache proxy_pass |
| 7 | Git-репозиторий | MANUAL | Ввод owner/repo + token |
| 8 | Поиск базы данных | AUTO | Поиск *.db (до 3 уровней) |
| 9 | Создание .gitignore | AUTO | Автоматически |
| 10 | Создание .env | AUTO | PORT, DATABASE_URL, SECRET_KEY |
| 11 | Сборка и запуск | AUTO | npm install + next build + pm2 start |
| 12 | Проверка репо и токена | CHECK | Авто + повтор при ошибке |
| 13 | Первый коммит и пуш | AUTO | git init + commit + push |
| 14 | Финальные проверки | AUTO | PM2, HTTP 200, .env, .gitignore |
| 15 | Настройка автодеплоя | AUTO | Webhook для GitHub |

## Требования на сервере

- **ОС**: Ubuntu / Debian
- **Node.js**: 18+
- **PM2**: `npm install -g pm2`
- **Веб-сервер**: Nginx или Apache
- **Python**: 3.8+ (с пакетом `rich`)

## Быстрый старт

### 1. Копируем файлы сайта на сервер

```bash
scp -r ./site-files/* root@your-server:/var/www/your-site.ru/
```

### 2. Создаём репозиторий на GitHub

Создайте приватный репозиторий и Fine-grained personal access token с правами **Contents** и **Webhooks**.

### 3. Запускаем скрипт

```bash
python3 autodeploy.py
```

Скрипт задаст несколько вопросов, а всё остальное сделает автоматически.

## Автоматические обновления

После настройки webhook (блок 15) при каждом push в репозиторий GitHub сервер автоматически:

1. Подтягивает изменения (`git pull`)
2. Устанавливает зависимости (`npm install`)
3. Собирает проект (`npm run build`)
4. Перезапускает через PM2
